# Prompts

Reusable prompt templates for this repository — for example, the "adopt repository architecture" prompt template already established in `documentation/FLUTTER_APP_INSTRUCTIONS.md` and the agent prompt template in `AGENTS.md`.

Add a prompt here when it's been used more than once and is worth not re-deriving. Name files descriptively, e.g. `flutter_feature_prompt.md`, `backend_feature_prompt.md`, `research_task_prompt.md`. Keep each prompt's placeholders (`[PROJECT_NAME]`, `[SHORT_REQUIREMENT]`, etc.) explicit and consistent with the style already used elsewhere in this repository, so a prompt copied from here doesn't need to be re-learned.
