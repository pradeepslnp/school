# Agent Outputs

Retained agent-generated artifacts live here — not temporary scratch files, not every draft, only outputs intentionally kept.

Organise by:

```
outputs/<agent>/<YYYY-MM-DD>/<task-slug>/<module>/
```

For example: `outputs/research_agent/2026-08-21/push-provider-comparison/notifications/`.

Do not store temporary files here. If an artifact isn't worth someone finding six months from now, it doesn't belong in this directory — put it in the agent's own scratch space instead.
